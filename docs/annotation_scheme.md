## Требования к аннотациям

### Текстовая модальность

**Типы сущностей:**
- `MODEL_NAME` — название архитектуры («свёрточная нейронная сеть», «трансформер»)
- `RESEARCHER` — имя исследователя («Ян Лекун», «Джеффри Хинтон»)
- `YEAR` — год (1989, 2017)
- `ORGANIZATION` — организация (Google, OpenAI)
- `TERM` — ключевой термин («свёртка», «pooling», «attention»)
- `ABBREVIATION` — аббревиатура (CNN, RNN, LSTM)

**Атрибуты:**
- Для `MODEL_NAME`: тип, год создания
- Для `TERM`: определение, связанная модель
- Для `RESEARCHER`: область, вклад

### Графическая модальность

**Типы объектов:**
- `LAYER` — слой (входной, скрытый, выходной)
- `NEURON` — нейрон
- `CONNECTION` — связь между нейронами
- `ACTIVATION` — функция активации (ReLU, Sigmoid, Softmax)
- `INPUT/OUTPUT` — входные/выходные данные

**Атрибуты:**
- Для `LAYER`: тип (conv / pooling / dense), размер, позиция
- Для `NEURON`: номер, слой
- Для `CONNECTION`: вес, направление

### Аудиомодальность

**Типы сущностей:**
- `TERM_AUDIO` — произносимый термин
- `DEFINITION` — определение (звуковой фрагмент)
- `EXAMPLE` — пример (звуковой фрагмент)
- `TRANSITION` — переход между темами

**Атрибуты:**
- Для `TERM_AUDIO`: начало, конец, длительность, соответствующий термин
- Для `DEFINITION`: связанный термин, длительность

## Уровни аннотаций

| Модальность | Уровень 1 | Уровень 2 | Уровень 3 |
|-------------|-----------|-----------|-----------|
| Текст | Модель (MODEL_NAME) | Термин (TERM) | Токен (TOKEN) |
| Изображения | Область (REGION) | Слой (LAYER) | Нейрон (NEURON) |
| Аудио | Фрагмент (SEGMENT) | Термин (TERM_AUDIO) | Фонема (PHONEME) |

### Расшифровка уровней

**Текст:**
- Уровень 1: Название типа нейронной сети
- Уровень 2: Ключевые термины
- Уровень 3: Отдельные токены с морфологическими атрибутами

**Изображения:**
- Уровень 1: Область изображения
- Уровень 2: Слои
- Уровень 3: Отдельные нейроны и связи

**Аудио:**
- Уровень 1: Смысловой фрагмент лекции
- Уровень 2: Термин, произнесённый в аудио
- Уровень 3: Фонемы / отдельные звуки

## Верификация аннотаций

### Обучение аннотаторов
- Инструкция с примерами разметки для каждой модальности
- Обучение на 5 эталонных примерах

### Критерии качества
- **Текст:** точность выделения терминов не менее 95%
- **Изображения:** правильность bounding box (IoU ≥ 0.85)
- **Аудио:** точность временных границ ±0.5 сек

### Перекрёстное аннотирование
- Два аннотатора независимо размечают 20% данных
- Сравнение результатов и обсуждение расхождений

### Проверка ошибок
- Каждый 5-й файл проверяется экспертом
- При обнаружении ошибок — дополнительная верификация

### Итеративный процесс
- После корректировок — повторная разметка части данных

### Документирование
- Ведение журнала верификации в `docs/verification_log.md`
